# المنصة الحالية وحدود الثقة

هذه نظرة عربية إلى معمارية المصدر الحالية، وليست شهادة بأن كل تغيير نُشر أو اجتاز تقييمًا حيًا. يحدد قفل الإصدار والصور المرصودة ما يعمل فعليًا. تُقيّم الصور نفسها ضمن نطاق الاختبار المسجل، ولا يُنقل نجاح تقييم قديم تلقائيًا إلى مصدر أحدث.

## بوابة النموذج وإخفاء المعرّفات

تجمع خلية Model gateway ثلاثة أجزاء: حد البوابة `gateway-boundary`، وخدمة الإخفاء `redactor`، وبوابة LiteLLM الخاصة. يفحص الحد الموثوق هوية المتصل وشكل الطلب ويخفي الأنماط المدعومة قبل إرسال الرسائل المقبولة. لا تتيح مفاتيح العامل العامة استخدام مسار المزوّد الخاص مباشرة. الإخفاء داخل مكتبة العامل حماية إضافية وليس سلطة الإنفاذ الوحيدة.

تغطي الأنماط المدعومة البريد الإلكتروني، وصيغ الهاتف والبطاقات وآيبان المدعومة، والحسابات المصرفية المسبوقة بوصف، وصيغ الهوية الوطنية والإقامة السعودية والأرقام الضريبية المدعومة. **لا تُخفى أسماء الأشخاص ولا أرقام جوازات السفر.** تعتمد المطابقة على الصيغة والسياق، ولا تشمل كل المعلومات الحساسة. عدد الفحوص أو غياب النتائج لا يثبت خلو النص من بيانات حساسة.

## وسيط البيانات والهوية

تتحقق البوابة الأمامية المالية الموثوقة من تسجيل الدخول والجلسة، وتوجّه المستخدم إلى عامل مرتبط به. تصدر صلاحية قصيرة العمر مرتبطة بالمستخدم والعامل. يتحقق وسيط البيانات من التوقيع والسريان والارتباط قبل تشغيل أدوات القراءة المسجلة تحت أمان الصفوف الإجباري.

لا يحمل العامل بيانات اتصال بقاعدة البيانات أو مفاتيح الجلسة أو التوقيع، ولا يملك مسارًا مباشرًا إلى Postgres. يختار الوسيط هوية الصفوف خارج العامل. يمكن للمستخدم إضافة مصروفاته عبر الواجهة الموثوقة؛ أدوات العامل تقرأ فقط ولا تمنحه اختيار مستخدم آخر.

## العمليات وموافقة المالك

يراقب عامل Ops الحالة ويقترح إجراءً، لكنه لا يملك صلاحية تعديل أحمال العمل. يوقّع التطبيق الموثوق موافقة المالك. يتحقق منفّذ الموافقات المستقل من التوقيع والهدف والفعل ونسخة المورد والمهلة والحالة قبل تعديل محدود تحكمه RBAC وسياسة القبول. يبقى نص النموذج شرحًا للعرض ولا يمنح سلطة.

يُعلن مخزون صلاحيات واحد الأدوار والارتباطات والجهات المسموحة، ومنها مرجع دور المنفّذ وهويته الدقيقة. تُعد الجهات الإضافية نتائج فحص. لا يتحول الفحص القديم أو الناقص أو غير القابل للقراءة إلى حكم حالي بأن النتائج صفر. تعني نتيجة فحص الوضع الأمني مقارنة محدودة، لا تقييمًا أمنيًا شاملًا.

## الواجهات والأحداث والحدود

تُفتح وحدة التحكم والواجهة المالية والدليل عبر التحويل المحلي المعتمد، دون واجهة عامة لأحمال العمل. الجواز يميز المرصود والمستنتج والمعلن والفاشل. شاشة Onboard مراجعة للحقائق ولا تنشئ وكيلًا. يعرض مؤشر الاتصال نتيجة آخر طلب وزمن وصولها إلى المتصفح، ولا يحكم على صحة كل الخدمات أو حداثة بياناتها.

يعرض أثر العامل بيانات وصفية أبلغ عنها، وليس تدقيقًا مستقلاً لكل حدود الطلب. تصدر المكونات أحداث طلب محدودة؛ لا يوجد وعد باكتمال التسجيل أو الاحتفاظ الدائم أو انتظار سجل تدقيق دائم قبل التغيير. تبقى حصص الأسئلة والرموز وتقييد الدخول ضمن ذاكرة العمليات الحالية، ولا تمثل حصصًا دائمة موزعة عبر إعادة التشغيل والنسخ.

## الإصدار وموارد الاختبار

قفل الإصدار المختار هو سلطة صور النشر، ولا يكفي اسم وسم أو نجاح تاريخي. تُجمّد نسخة المصدر وتُبنى صورها وتُتحقق تواقيعها وشهاداتها وربطها بالمصدر، ثم تُنشر البصمات نفسها وتُقيّم ضمن النطاق المعتمد. يبقى اختبار هجوم غير مُمارس نتيجة غير مكتملة وليس نجاحًا.

يُحتفظ بالجهازين `secure-infra-worker` و`sfai-engineering` وأقراصهما حتى يطلب المالك الحذف صراحة. تُبنى صور الإصدار على مشغّلات GitHub المستضافة، وتُجرى اختبارات التطوير على VM الهندسة. تنظيف مشروع التقييم المؤقت لا يشمل المشروع الأصلي أو جهازي الهندسة.
